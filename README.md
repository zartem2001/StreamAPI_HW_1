# Задача: Работа с числами — коллекции vs Stream API

## 📋 Описание задачи

Дан список чисел: `1, 2, 5, 16, -1, -2, 0, 32, 3, 5, 8, 23, 4`.

Необходимо:
1. Отфильтровать положительные числа.
2. Найти среди них чётные.
3. Отсортировать по возрастанию.
4. Вывести результат на экран.

Реализовать **два способа**:
- **Класс `Main`** — без Stream API, через обычные коллекции и циклы.
- **Класс `StreamMain`** — с использованием Stream API.

## 🎯 Цель

Сравнить два подхода к обработке коллекций в Java — классический (итеративный) 
и функциональный (Stream API). Понять, насколько Stream API упрощает код.

## 🛠️ Используемые технологии

- Java 17+
- Коллекции (`ArrayList`, `Collections`)
- Stream API
- Лямбда-выражения
- Ссылки на методы (`System.out::println`)
- `Comparator`
